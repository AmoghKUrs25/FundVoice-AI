# FundVoiceAI

## Mutual Fund Portfolio Voice Reporter

FundVoiceAI is a project intended to help investors understand
their mutual fund portfolios through portfolio valuation,
NAV verification, and a planned AI-powered voice interface.

## Current Progress

- Portfolio and NAV data models
- Portfolio valuation calculations
- NAV retrieval and CSV parsing
- NAV verification engine
- Automated unit tests
